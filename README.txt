# Eastfits Storefront

Open `index.html` in a browser or in VS Code with Live Server.

Included:
- Responsive Eastfits-style storefront
- Sticky header + search
- Product catalogue and category filters
- Wishlist feedback
- Working cart drawer
- Product detail modal
- Demo M-Pesa checkout button
- Newsletter form
- Mobile layout
- Local SVG product artwork, so the demo does not depend on paid image assets

Replace the SVGs in `assets/` with real product photography when available.
